# Run inspectability and cost

Status: draft
Ladders to: docs/product/one-pager/current.md §4 Run inspectability and cost

## 1. User problem

- Who: software engineers improving their agentic coding workflow.
- Friction: a run that nobody watched cannot be reconstructed or priced
  afterwards, which makes an unattended workflow hard to trust.
- Outcome: receipts, trajectory, report, and prompt-cache accounting, so an
  engineer can see what a run did and what it cost without having sat
  through it.
