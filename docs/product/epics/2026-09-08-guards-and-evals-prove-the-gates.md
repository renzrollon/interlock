# Guards and evals that prove the gates

Status: draft
Ladders to: docs/product/one-pager/current.md §4 Guards and evals that prove the gates

## 1. User problem

- Who: software engineers improving their agentic coding workflow.
- Friction: a gate written as prose can be re-argued by the model, and nothing
  shows whether a gate actually fired during a run.
- Outcome: fail-open hooks plus eval suites that show each gate fires, so the
  human-in-the-loop gate is backed by code an engineer can check.
