### ↩️ Rollback

Reverting the commits does not migrate data. The run-evidence file stays `interlock.merge-evidence/1`; the carry is a read-time filter and does not rewrite the file, so old code still sees the original `review`, `verify`, `handoff`, `coverage` and `run` keys. Optional `head` and `dimensions` on a review record, `head` on a verification verdict, and `head` on a handoff are ignored by code that does not read them. `risk.class` goes back to reading artifact text and test paths; nothing was stored from the new class. The legend line and the ship-summary line disappear from future output; bodies already posted on a merge request stay as posted.

**One exception:** reverting `boundToHead` makes a `--review`, `--verify` or `--handoff` file whose `head` names another commit count again. The new code is what drops it.
