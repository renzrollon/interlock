## Summary
- At a halt or a checkpoint, people still copy commands out of a wall of markdown. Nobody in another window hears that a run stopped. A send-back at the checkpoint is recorded nowhere. This change closes those gaps (Epic 4 of `docs/notes/2026-10-31-five-epics.md`). The hooks module still decides nothing: it draws, drafts and tells, and the person's Enter is the act.
- **Halt and checkpoint cards get controls.** A press drafts the exact command line the card printed into an empty prompt box, or copies it when the box already holds a draft. Nothing is submitted. The new `interlock checkpoint <change>` prints the checkpoint card in any session, and the two send-back outcomes print `interlock autonomy record spec --human-override`.
- **Waves, notifications and suggestions.** Desktop and VS Code draw the wave plan as an SVG diagram above the board, which stays as its text alternative. Halts, closes, checkpoints and quiet runs are told through the engine's notification, with a toast fallback. The prompt suggests open change names and recent run ids. The new `interlock run-log follow` is the notification's twin for `-p`, cloud and `interlock-run` runs.
- **BREAKING: the mods floor rises from Claude Code 2.1.287 to 2.1.295.** Below it the panes are off and the doctor's `mods` row says so. The run itself is unchanged.
