### ↩️ Rollback

Reverting is safe for data. Nothing in this PR adds a corpus, a record schema or a stamp. The two new preflight report fields are dropped by the old reader, which rebuilds the report from known keys, and the next SessionStart rewrites the file without them. `told`, `suggest` and `quietStretch` live only in module memory. `interlock checkpoint` and `run-log follow` only read. A revert puts the floor back to 2.1.287, which also moves the CI floor leg back, and switches the panes back on for 2.1.287–2.1.294. **One exception:** an `interlock autonomy record spec --human-override` that a person typed from the card's send-back line stays in the autonomy state after a revert: `runs` and `human_overrides` incremented, `consecutive_clean` zeroed, L3 demoted to L2. That is valid data under the old code, which writes the same records. It does not go away.
