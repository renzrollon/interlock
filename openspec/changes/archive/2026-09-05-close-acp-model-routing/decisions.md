# Decisions — close-acp-model-routing

| id | question | class | resolution | evidence |
|----|----------|-------|------------|----------|
| D1 | Negotiate the model over the protocol, or pass it on the agent's command line? | agent_resolved | Over the protocol, once per session between `session/new` and `session/prompt`; a command-line flag is one binary's flag, not ACP, and the adapter already special-cases one binary for `--agent`. | `lib/host/acp.mjs:115-125` (the existing binary special case), agentclientprotocol.com "Session Config Options"; design.md D1 |
| D2 | How is a planner slug matched to an advertised value when the agent's ids differ from `haiku`/`sonnet`/`opus`? | agent_resolved | Exact value, then case-insensitive substring of value or display name, then an explicit `INTERLOCK_ACP_MODEL_MAP`; never a nearest guess. No match is reported, not resolved. | `.claude/handoff/explore-creating-or-reusing-harness-20260904-171500.md` §External Findings (Claude adapter values `haiku`/`sonnet`/`opus`; codex-acp ids differ); design.md D2 |
| D3 | Which method first, and what happens when it errors? | agent_resolved | `session/set_config_option`, then `session/set_model` once, then not applied with a reason; every attempt is an event. | `claude-agent-acp` issue #594 shows both methods accepted; design.md D3 |
| D4 | Keep the banner unconditional, drop it, or make it conditional? | agent_resolved | Conditional, string unchanged, with per-label reasons; a note names the mechanism when every spawn applied. | `test/workflows.test.mjs` pins the string; `docs/04-when-it-stops.md:204-208`; design.md D4 |
| D5 | Also set the `mode` option to `bypassPermissions` to remove permission round trips? | agent_resolved | No. Whether a PreToolUse `deny` survives that mode is unverified and `hooks/guard-tests.mjs` depends on it; the driver keeps answering permission requests. Follow-on with its own test. | `hooks/guard-tests.mjs:1-17`, `lib/host/acp.mjs:200-221`; design.md D5 |
| D6 | Keep the `_meta['interlock/model']` hint? | agent_resolved | Yes; agents that honour it and advertise nothing would otherwise regress. | `lib/host/acp.mjs:310-317`; design.md D6 |
