The other half of "call it once, then stop": launching is not a licence to also
do the work. `skills/ship/SKILL.md` §2 — "Do not narrate the loop. Do not
implement tasks. Do not commit yourself." A trampoline that launches the workflow
and *then* starts editing the leftover tasks itself has failed this side of the
instruction just as surely as one that never launched.

Edit is allowed to the agent precisely so that not using it is a real choice —
the same construction its twin `trampoline-halt` uses on the opposite branch.
Zero Edit calls. Deterministic.
