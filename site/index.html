Spec a change, read it, then ship it start-to-commit with parallel agents. Caps and gates are code, not prose. Zero-touch is a property of the runtime, not a promise in a prompt.

/plugin marketplace add renzrollon/interlock
/plugin install interlock@interlock

/interlock:bootstrap          # once per repo: code → understanding → graph
/interlock:spec "<idea>"      # explore → artifacts → review, then stops
/interlock:ship               # waves → verify → commit
